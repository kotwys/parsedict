# Структура данных для словаря «Лексики бесермян»

Вывод в формате YAML представляет собой поток (stream) из документов, каждый из
которых является представлением одной словарной статьи.  Поток статей не
отсортирован.

Отдельная словарная статья представлена типом [Entry](#Entry).  В зависимости от
способа оформления статьи в словаре, может использоваться разный набор полей.
Поля, значениями которых выступают ложные значения (`false`, пустые
последовательности), опускаются в итоговом документе.

Большинство представленных ниже типов являются словарями (наборами
ключ—значение) с описанием полей.  Если тип расширяет другой тип, то все поля
расширяемого типа включаются в данный тип.

## Типы данных

### HTMLLike

Строка, которая может включать HTML-подобную разметку (`<b>`, `<i>`, `<sup>` и
т. д.).  На данный момент поддерживается только базовая визуальная разметка, но
в дальнейшем может быть введена семантическая разметка (например, выделение
словарных помет).

### Headword

Заглавное слово.

#### Поля

- **value**: str

    Заглавное слово.  В случае устойчивых выражений может включать слова в
    скобках (необязательные слова или варианты).

- **homonym_id**: str?

    Номер омонима (римская цифра).

- **assumed**: bool

    Истина, если словарная форма предполагаемая или заимствована не из трудов
    Т. И. Тепляшиной. Обозначается знаком звёздочки.

### HeadwordAndPronunciation

Заглавное слово с произношением (например: **гондөр** (*gə̑ndə̑r*)).

**Расширяет** [Headword](#Headword).

#### Поля

- **pronunciation**: HTMLLike

    Произношение, записанное уральским фонетическим алфавитом.  Может включать
    HTML-подобную разметку (`<sup>`, `<b>`).

- **region**: sequence&lt;str&gt;

    Пометы районов, где зафиксирован вариант произношения.

### HeadwordRef

Ссылка на словарную статью (с возможным указанием на отдельное значение или
устойчивое выражение).

**Расширяет** [Headword](#Headword).

#### Поля

- **variant**: Headword?

    Фонетический вариант (после знака тильды).

- **sense_number**: str?

    Номер значения в словарной статье, на которое даётся ссылка (число,
    записанное арабскими цифрами).  Может также быть приведён промежуток (1–3).

- **subphrase**: Headword?

    Ссылка на конкретное устойчивое выражение в словарной статье.

### Reference

Ссылка на другую словарную статью (например: *сущ. от* **мөнөнө**).

#### Поля

- **label**: str

    Помета перед ссылкой (например: *сущ. от*).

- **base**: sequence&lt;Headword&gt; (*min*=1)

    Целевые заголовочные слова.

### Example

Иллюстративный материал.  Состоит из текста на бесермянском языке и следующего
за ним пояснения на русском языке.

#### Поля

- **label**: str?

    Словарные пометы перед примером.

- **text**: HTMLLike

    Текст примера на бесермянском языке (обычно на латинице, но не всегда).
    Визуально оформлено курсивом (сама разметка не включает тэг `<i>`).

- **description**: HTMLLike

    Пояснение к примеру (часто — перевод на русский язык).

- **source**: "monograph" | "filecabinet"

    Источник, откуда был заимствован пример.  Примеры с **source**="monograph"
    идут перед примерами с **source**="filecabinet".  В словаре примеры с
    **source**="filecabinet" обозначаются знаком ○.

### SenseLexical

Простое значение в словаре с толкованием.

#### Поля

- **type**: "lexical"

- **derivation**: sequence&lt;Reference&gt;

    Ссылка на производящие основы.  Несколько вариантов задаются через длинное
    тире.

- **translation**: HTMLLike

    Толкование значения.

- **examples**: sequence&lt;Example&gt;

    Блок иллюстративного материала.

### SensePhrase

Значение, описываемое через устойчивое выражение (сочетание) с другим словом.

#### Поля

- **type**: "phrase"

- **translation**: HTMLLike

    Текст перед устойчивым выражением (обычно включает словарные пометы или
    указание на синонимы).

- **phrase**: Phrase

    Описание устойчивого выражения.

### DetachedExamples

Блок примеров, относящийся к нескольким значениям.

#### Поля

- **type**: "examples"

- **examples**: sequence&lt;Example&gt; (*min*=1)

### EntrySingleSense

Статья только с одним значением заглавного слова.

#### Поля

- **senses**: sequence&lt;SenseLexical&gt; (*min*=1, *max*=1)

### EntryMultipleSenses

Статья с несколькими значениями заглавного слова.  Значения в словаре имеют
порядковый номер, записанный арабскими цифрами.

#### Поля

- **prolog**: HTMLLike?

    Вступительный текст перед списком значений (например, словарные пометы).

- **senses**: sequence&lt;SensePhrase | SenseLexical | DetachedExamples&gt; (*min*=1)

### EntryExamplesOnly

Словарная статья, включающая только примеры.

#### Поля

- **senses**

    Включает всегда один элемент-словарь со следующими полями:
    - **type**: "examples"
    - **examples**: sequence&lt;Example&gt; (*min*=1)

### Phrase

Устойчивое выражение или сочетание.

**Расширяет** [EntryExamplesOnly](#EntryExamplesOnly) | [EntryMultipleSenses](#EntryMultipleSenses) | [EntrySingleSense](#EntrySingleSense).

#### Поля

- **headword**: sequence&lt;HeadwordAndPronunciation&gt;

### EntryPhraseological

Словарная статья, описывающее слово с помощью устойчивых выражений (обычно
наречно-изобразительные слова).

#### Поля

- **prolog**: HTMLLike?

    Вступительный текст перед списком значений (например, словарные пометы).

- **senses**: sequence&lt;SensePhrase&gt; (*min*=1)

### Entry

Корень словарной статьи.

**Расширяет** {} | [EntryPhraseological](#EntryPhraseological) | [EntryMultipleSenses](#EntryMultipleSenses) | [EntrySingleSense](#EntrySingleSense).

#### Поля

- **headword**: sequence&lt;HeadwordAndPronunciation&gt; (*min*=1)

- **derivation**: Reference?

    Информация о производящей основе.

- **phrases**: sequence&lt;Phrase&gt;

    Устойчивые выражения.

- **commentary**: sequence&lt;HTMLLike&gt;

    Лексический материал (объяснение этимологии и т. д.).  Элементы
    последовательности представляют отдельные абзацы.

- **doublets**: sequence&lt;HeadwordRef&gt;

    Ссылки на диалектные дублеты (после пометы «см. тж.» = «смотри также»).

- **compare**: sequence&lt;HeadwordRef&gt;

    Ссылки на исходные слова (после пометы «ср.» = «сравни»).
